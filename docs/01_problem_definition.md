# 1단계. 문제 정의와 지표 설계

## 1. 비즈니스 질문

> **UCLA 학생 한 명이 학기 중 살 곳을 고를 때, 비용과 통학을 함께 고려하면 어디가 가장 합리적인가?**

- **의사결정자**: 기숙사 계약 기간이 끝나 거주지를 다시 정해야 하는 UCLA 학생 (특히 편입생, 3~4학년, 대학원생)
- **결정 내용**: 대학 주거(기숙사, University Apartments)에 남을지, Westwood에서 렌트할지, 더 먼 지역으로 나갈지. 룸메이트를 몇 명과 함께 살지.
- **결과물이 답해야 하는 것**: "내 조건(룸메이트 수, 통학 수단)이라면 어디가 가장 싸고, 그 차이는 얼마인가?"

## 2. 비교 대상 (선택지)

| 그룹 | 대상 | 비고 |
| --- | --- | --- |
| 대학 주거 | 기숙사(Residence Halls), University Apartments | UCLA Housing 공식 요금. 기숙사는 식비 포함이라 분리 필요 |
| 캠퍼스 인접 | Westwood (90024) | 도보 통학 |
| 근거리 | West LA / Sawtelle (90025), Rancho Park (90064), Brentwood (90049) | 자전거·버스 통학 |
| 원거리 | Palms (90034), Mar Vista (90066), Koreatown (90005, 90020) | 버스 통학, 렌트가 상대적으로 낮다고 알려진 지역 |

최종 ZIP 목록은 2단계에서 데이터가 있는 곳 기준으로 확정한다.

## 3. 지표 정의

### 주 지표: 1인당 월 실질 주거비 (Effective Monthly Cost per Person)

```
실질 주거비 = 1인당 렌트 + 1인당 공과금 + 통학 비용 + 통학 시간 비용
```

| 구성 요소 | 정의 | 출처 / 가정 |
| --- | --- | --- |
| 1인당 렌트 | 유닛 렌트 ÷ 거주 인원 | 침실당 1명(개인실) 또는 2명(방 공유) 두 시나리오 |
| 1인당 공과금 | 전기·인터넷 등 월 추정치 ÷ 거주 인원 | HUD 기준 렌트는 공과금 포함 기준이므로 출처별로 맞춰 조정 |
| 통학 비용 | 교통비 (버스, 자전거, 차량) | UCLA 학생 교통 요금 기준 |
| 통학 시간 비용 | 왕복 통학 시간 × 월 통학일수 × 시간 가치 | 시간 가치 = LA 최저임금 (민감도 분석으로 0원~2배 범위 확인) |

**대학 주거 비교 시 주의**: 기숙사 요금에는 식비가 포함되므로, 식비 플랜 비용을 빼거나 렌트 지역에 식비를 더해 같은 기준으로 맞춘다.

### 보조 지표
- **1인당 렌트만** (시간 비용을 빼고 순수 현금 지출만 보기)
- **렌트 상승률 (전년 대비)**: 지역별로 앞으로 비싸질 가능성
- **통학 시간 (분)**: 비용으로 환산하지 않은 원래 값

### 지표를 이렇게 정한 이유
- 렌트만 비교하면 "멀수록 싸다"는 당연한 결론만 나온다. 통학 시간을 비용에 넣어야 실제 선택의 트레이드오프가 드러난다.
- 시간 가치는 사람마다 다르기 때문에 하나의 값을 정답으로 두지 않고 범위로 보여준다(민감도 분석).
- 유닛 렌트가 아니라 1인당 비용으로 비교해야 기숙사(1인당 요금)와 같은 기준이 된다.

## 4. 가설

| # | 가설 | 확인 방법 |
| --- | --- | --- |
| H1 | Westwood는 유닛 렌트가 가장 비싸지만, 룸메이트와 방을 공유하면 기숙사보다 1인당 비용이 낮다 | 지역 × 거주 인원별 1인당 렌트 비교 |
| H2 | 통학 시간 비용을 포함하면 원거리 지역의 비용 이점은 크게 줄거나 사라진다 | 실질 주거비 비교, 시간 가치 민감도 분석 |
| H3 | Westwood 렌트는 주변 지역보다 빠르게 오르고 있다 | ZIP별 렌트 지수 전년 대비 상승률 |
| H4 | 침실 하나가 늘어날 때 1인당 비용은 줄어든다 (규모의 경제) | 침실 수별 기준 렌트 ÷ 인원 |

## 5. 데이터 계획

| 데이터 | 내용 | 단위 | 용도 |
| --- | --- | --- | --- |
| Zillow Observed Rent Index (ZORI) | 시장 렌트 지수, 월별 | ZIP × 월 | 지역별 수준과 추이 (H3) |
| HUD Small Area Fair Market Rents (FY2026) | 침실 수별 기준 렌트 | ZIP × 침실 수 | 침실 수별 1인당 비용 (H1, H4) |
| UCLA Housing 2026-27 요금표 | 기숙사, University Apartments 1인당 요금 | 유형 × 인원 | 대학 주거 비교 기준 |
| 캠퍼스까지 거리 | ZIP 중심점 → UCLA | ZIP | 통학 시간과 비용 (H2) |
| (선택) Census ACS | ZIP별 중위 렌트, 세입자 비율 | ZIP | 교차 검증 |

모든 데이터는 공개 출처에서 내려받고, 출처 URL과 다운로드 날짜를 `data/README.md`에 기록한다.

## 6. 한계와 가정 (미리 밝혀 둘 것)
- ZIP 단위 지수는 개별 건물 차이(신축, 고급 건물)를 반영하지 못한다.
- HUD 기준 렌트는 시장 중위값이 아니라 40번째 백분위수 기준이라 실제 호가보다 낮을 수 있다. ZORI와 비교해 차이를 확인한다.
- 통학 시간은 거리 기반 추정치이며 실제 교통 상황을 반영하지 않는다.
- 방 공유 여부, 주차비, 가구 유무 등 개인 선호는 시나리오로만 다룬다.
