# 4단계. 민감도 분석, 손익분기, 추천표

쿼리: `sql/06_sensitivity.sql`, `07_win_share.sql`, `08_recommendation.sql`, `11_time_value_breakeven.sql`
결과: `data/processed/sensitivity_full.csv` (1,080행 × 선택지), `07~08, 11` CSV

## 1. 무엇을 바꿔 봤나

주 지표: **1인당 연간 실질 비용 = 렌트 + 통학 현금 비용 + 통학 시간 × 시간 가치**

| 가정 | 값 | 이유 |
| --- | --- | --- |
| 렌트 추정 방식 | ZORI 보정 / SAFMR 그대로 / SAFMR × 1.1 | 추정 렌트의 불확실성 |
| 여름 계획 | LA를 떠남 / 서브렛 50·70·90% / LA에 남음 | UCLA 9개월 vs 외부 12개월 계약 |
| 통학 방식 | 대중교통 / 보유 차량 운전 / 차를 사서 운전 | 차가 있는 학생이 많은 동네(예: Koreatown) 반영 |
| 시간 가치 | $0 / $20 / $35 per hour | 사람마다 다름 |

3 × 5 × 3 × 3 = 135개 시나리오 × UCLA 유형 8개 = **1,080개 비교**. Westwood와 UCLA 아파트 거주자는 모든 시나리오에서 도보로 통학한다.

## 2. 결과

### (1) 시간 가치가 가장 큰 변수다 (`07`)

| 통학 방식 | $0/hr | $20/hr | $35/hr |
| --- | --- | --- | --- |
| 대중교통 | Koreatown 92%, UCLA 8% | UCLA 62%, Palms 28%, Westwood 10% | UCLA 73%, Westwood 26% |
| 보유 차량 | Koreatown 70%, UCLA 30% | UCLA 73%, Westwood 26% | UCLA 74%, Westwood 26% |
| 차량 구입 | UCLA 74%, Westwood 26% | UCLA 74%, Westwood 26% | UCLA 74%, Westwood 26% |

- 시간을 공짜로 보면 렌트가 가장 싼 Koreatown이 대부분 이긴다. 시간을 시급 $20로 보는 순간 Koreatown은 한 번도 이기지 못한다.
- 차를 사서 먼 동네에 사는 선택은 시간을 0원으로 봐도 이기지 못한다. 보유비(월 약 $408)가 렌트 절약보다 크다.

### (2) 손익분기 시간 가치 (`11`, 2베드 4인, 주 렌트 추정)

| 동네 | 대중교통, 여름에 떠남 | 대중교통, 서브렛 70% | 보유 차량, 서브렛 70% |
| --- | --- | --- | --- |
| Palms | $17.9 | $35.0 | $21.1 |
| Koreatown | $12.6 | $19.2 | $10.0 |
| West LA / Sawtelle | $0.7 | $17.6 | $13.4 |
| Mar Vista | $4.8 | $17.4 | $11.2 |
| Rancho Park | UCLA가 항상 쌈 | $17.5 | UCLA가 항상 쌈 |
| Brentwood | UCLA가 항상 쌈 | $1.4 | UCLA가 항상 쌈 |

읽는 법: "통학 시간을 시간당 이 금액보다 낮게 본다면 이 동네가 UCLA 아파트보다 싸다."

### (3) 차가 먼 동네를 구해 주지 않는 이유
- Koreatown은 운전(57분 + 주차·도보 10분)이 대중교통(59분)보다 빠르지 않다. 차를 쓰면 시간은 그대로이고 월 $201가 더 든다.
- 운전이 빠른 곳(Sawtelle, Brentwood, Mar Vista)도 7~12분 차이라, 시간 가치가 시간당 $23~35 이상일 때만 운전이 대중교통보다 이득이다.

### (4) 대표 사례: 2베드 4인, 서브렛 70%, 대중교통, 시급 $20
Palms $11.4K < Westwood $12.0K < UCLA $13.0K < Rancho Park $13.2K ≈ Koreatown $13.2K < Sawtelle $13.3K < Mar Vista $13.4K < Brentwood $14.9K

같은 조건에서 여름에 LA를 떠나면: UCLA $13.0K < Palms $13.2K < Westwood $14.4K

## 3. 추천표 (`08`은 2베드 4인 기준, 세 렌트 추정 방식에서 결과가 같으면 robust)

| 상황 | 추천 |
| --- | --- |
| 여름에 LA를 떠나고, 통학 시간을 $20/hr 이상으로 본다 | UCLA 아파트 |
| 서브렛·체류, 대중교통, 시간 가치 중간 | Palms, 다음은 Westwood |
| 서브렛·체류, 시간을 중시 | Westwood 또는 UCLA 아파트 |
| 통학 시간을 거의 신경 쓰지 않는다 | Koreatown |
| 먼 동네에 살려고 차를 산다 | 비추천 (모든 시나리오에서 손해) |

## 4. 한계
- 시간 가치 세 값($0/$20/$35)은 범위를 보여주기 위한 선택이다. 손익분기 표로 보완했다.
- 통학 시간은 동네별 대표 지점 하나, 평일 오전 9시 도착 기준이다.
- 차량 비용은 AAA 신차 기준 전국 평균이고, UCLA 주차권은 보장되지 않는다.
- 서브렛 회수율, 통학 일수(월 16일), 주차·도보 10분은 가정값이다.
